# MVP 演示验收清单

## 当前状态

目前仅为工程骨架，以下业务项尚未完成。不能把页面预览或历史旧版评估分数作为新版业务验收结果。

## 必须跑通的路径

- [ ] 创建专题并刷新后仍可看到。
- [ ] 上传公开的文本型 PDF / Markdown / TXT，显示处理中、可用或明确失败原因。
- [ ] 选择指定资料提问，向量和 BM25 均不带入未选择的来源。
- [ ] 真实流式回答；资料不足时明确说明，模型错误不得伪装成功。
- [ ] 点击引用查看真实片段、来源与 PDF 页码（如适用）。
- [ ] 保存回答为笔记，编辑并导出 Markdown。
- [ ] 重启后资料、会话、笔记保留；导入中断可重试。
- [ ] 彩排完整主线，准备真实录屏作为明确标注的备用演示。

## 不属于本次 MVP

注册登录、多用户隔离、公网部署、多人协同、OCR、任意网页抓取、音视频生成、复杂 Agent 编排、模型训练。

## 骨架验证

运行 README 中的测试和构建命令。健康接口必须明确标识 `business_ready: false`，直到真实业务验收完成后再更新状态协议。
