# MVP 演示验收清单

- [x] 专题创建、资料上传、解析、片段位置、去重与重试。
- [x] 手动向量索引、状态、模型/维度/版本隔离。
- [x] 勾选来源、混合检索、流式问答、多轮追问和可点击引用。
- [x] 完整回答保存为独立笔记；重复保存复用，不覆盖编辑。
- [x] Markdown 编辑/预览、只读引用快照、自动和手动保存。
- [x] revision 冲突保护、输入保留、离开提醒。
- [x] 导出前保存最新版本，无效引用/冲突阻止导出；实际文件回读核验。
- [x] 笔记不自动入库、不改原回答，本轮笔记操作不调用模型。
- [x] 三栏布局完成后，使用全新独立专题与合成资料，通过真实模型完成全链路复验。
- [x] 两版数据比较、同来源追问、资料不足拒答、缩小来源不带入旧数据、刷新/重启后继续提问。

最新可重放材料：`samples/acceptance/`。实际结果及边界见 [真实链路验收记录](real-e2e-20261029.md)。

当前演示路径：上传 → 索引 → 提问 → 核对引用 → 保存笔记 → 编辑 → 导出。

待后续：联网发现资料、真实认证/多用户隔离、协同、笔记删除/复制/历史版本、索引维护和费用控制。本机 MVP 不代表已通过生产安全和通用问答准确率验收。
