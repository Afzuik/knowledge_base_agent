# 本轮演示清单：专题与资料入库

## 本轮已实现并测试

- [x] 创建专题、列表、详情；名称校验与固定身份范围。
- [x] PDF/Markdown/TXT 上传、处理状态、原文片段预览。
- [x] UTF-8、页码、字符位置、大小/页数/字符限制。
- [x] 同专题按内容去重；同名不同内容作为新资料。
- [x] 失败提示、重试记录、重试幂等、事务回滚。
- [x] 专题范围校验、原文件路径限制。
- [x] 刷新及服务重启后保留专题、资料与片段。
- [x] 中断任务恢复、缺失原文与临时/孤立文件处理。
- [x] 无模型网络调用；“已解析 / 未索引”不误报可问答。

## 下一阶段（本轮未实现）

- [ ] Embedding 与向量索引。
- [ ] 选择来源、真实问答与可核验引用。
- [ ] 会话消息、笔记编辑与 Markdown 导出。

## 不在范围内

注册登录、多用户安全隔离、公网部署、多人协同、OCR、网页抓取、音视频生成、复杂自主 Agent 编排。

测试范围和证据见 testing.md。测试通过不代表生产级隔离或对恶意文件的解析沙箱。
