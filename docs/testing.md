## 限制与警告

- 测试不等于多用户安全、恶意 PDF 沙箱、负载测试或生产级任务可靠性证明。
- 本轮只验证“已解析”，没有模型调用、向量检索、问答或引用正确性测试。
- Starlette TestClient 对 httpx 有一条弃用警告；npm 对本机 electron_mirror 配置有警告。均未导致测试或构建失败，本轮未修改用户全局配置。
- 如果磁盘/数据库故障连失败状态也无法写入，日志会记录错误；恢复存储后应重启服务，让中断恢复逻辑处理遗留 running 任务。
