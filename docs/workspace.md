# 三栏研究工作台

## 布局与操作

- **左侧**：资料来源在上、资料与片段预览在下。点击资料名称查看原文；“用于问答”复选框独立控制问答范围，预览不等于勾选。
- **中间**：研究对话。用户气泡靠右，知识助手靠左；支持 Markdown、引用、复制原始 Markdown、保存笔记。输入框留在聊天区底部。Enter 发送，Shift+Enter 换行，中文输入法确认不会误发送。
- **右侧**：笔记列表、编辑/预览和 Markdown 导出；原自动保存、冲突提示、导航保护不变。

## 调整栏宽

1. 拖动资料/对话、对话/笔记之间的竖边框。
2. 左侧最小 240 px、右侧最小 280 px，中间至少 340 px。窗口变小时自动收敛。
3. 双击任意边框恢复默认左右 300/330 px；实际宽度按窗口可用空间约束。
4. Tab 聚焦边框，左右方向键移动 10 px；Shift+方向键移动 40 px；Home/End 收至最小/最大。
5. 当前浏览器记住栏宽（localStorage 键 `knowledge-workbench:columns:v1`），不会保存资料正文和笔记。存储被禁止时仍可使用，但不能记忆。

屏幕宽度 ≤1000 px 时显示“资料与预览 / 研究对话 / 笔记与成果”切换按钮，不强行挤成三栏。切换不会卸载编辑器或中止当前对话。

## 片段与引用

片段每页只显示 **1 片**，调用真实分页接口 `limit=1`，用“上一片 / 下一片”浏览。只有 1 片时两按钮禁用且显示原因；换资料回到第一片。

点击回答的 `[S1]` 等有效引用，在左下查看**回答当时的证据快照**，不是用当前资料内容冒充旧证据；关闭引用返回原预览位置。

## 滚动与文字

资料列表、预览、聊天记录及笔记区域可独立滚动。正常浏览时文字可自由选择；只有拖动边框期间暂时禁止选择。聊天靠近底部时跟随新内容，上翻阅读时不自动拉回，可点“回到最新消息”。

Markdown 不执行 HTML、不自动加载远程图片。流式内容未完成时不提供可点击引用或保存笔记，避免把未验证标记当作最终证据。

## 架构边界

本轮仅调整第①界面层，不改数据库、应用用例、检索算法或模型配置。

- `WorkbenchPage` 组合资料/预览、研究对话、笔记三个区域。
- `ResizableWorkspace` 管理布局、键盘/指针调宽与本地宽度偏好。
- `SourcePreview` 使用已有 API 的 `offset` 与 `limit=1`；不在浏览器假分页，不重新解析资料。换来源重置页码，取消旧请求。
- `ChatPanel` 保持原 SSE/保存接口；引用快照交给左栏，保存笔记在右栏打开。
- 对话与笔记共用 `MarkdownContent`，稳定 Markdown 节点，避免资料轮询打断文字选择和引用按钮焦点。
- 窄屏通过显示/隐藏而非卸载组件保留编辑状态；原未保存导航保护仍然生效。

## 更新后如何使用

本次已构建前端。已运行本地后端时刷新页面即可读取新构建；尚未启动时在项目根目录执行 `bash scripts/run_local.sh`，再打开 `http://127.0.0.1:8765`。浏览器缓存旧资源时强制刷新。

## 变更与恢复

基线为提交 `2280d9094f74763bea166966aa3643671e892e0a`。本地 `reports/layout/before.tar` 保存基线，`change.patch` 保存本轮差异（含新增文件），`before.sha256` / `after.sha256` 记录源码哈希。

需要恢复时先备份当前工作区；确认没有后续改动，使用 `git apply --check -R reports/layout/change.patch` 检查，再执行 `git apply -R reports/layout/change.patch`，重新构建前端。若检查失败不要强行覆盖，按基线逐文件合并。本轮已在额外副本上验证补丁正向/反向应用，不触碰用户数据目录。
