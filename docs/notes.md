# 回答保存、笔记编辑与 Markdown 导出

## 范围与四层职责

本轮只增加确定性的笔记功能，不调用模型、不改问答流程、不把笔记自动加入索引。

- 界面层：回答下的保存按钮、专题笔记列表、Markdown 编辑/预览、自动保存、冲突/离开提醒、下载。
- 应用层：`application/notes.py` 校验范围和状态；`application/note_export.py` 分析引用、组织导出文本和安全文件名。
- AI 处理层：本轮无新增能力，笔记 CRUD 和格式化无需经过模型。
- 基础设施层：`infrastructure/database/note_repository.py` 原子复制回答/引用，使用 revision 条件更新。
- HTTP 入口：`api/notes.py` 只处理 DTO、状态码、响应头，不执行 SQL 或模型请求。

## schema v3：只增加 notes 表

字段：id、notebook_id、origin_message_id、title、body_markdown、citations_snapshot_json、revision、created_at、updated_at。

- 专题有外键；来源回答 ID 唯一，重复保存复用同一笔记，不覆盖已编辑内容。
- 来源回答 ID 是历史标识，不设置对 messages 的强依赖外键；保存时必须在事务中验证真实回答和归属。
- 正文和完整引用快照保存在同一行、同一事务。后续编辑原回答、原资料或重建索引，不会改写已保存的笔记快照。
- revision 是防覆盖版本号，不是可回滚的历史版本系统。
- 从 v1/v2 升级前自动备份数据库，随后事务化应用迁移；未知版本或无版本非空库仍拒绝覆盖。

## 使用流程

1. 在状态 complete 的助手回答下点击“保存为笔记”。生成中、失败、中断或用户消息不能保存。
2. 默认标题取对应问题的前 80 字，随后可修改；重复点击打开已有笔记。
3. 在“笔记与成果”中编辑标题/正文，停止输入约 1 秒后自动保存，也可立即保存。
4. 切换预览查看 Markdown、点击有效引用核对只读原文。
5. 点击导出；若有修改，先保存成功，再下载对应 revision 的 Markdown。

标题为去除首尾空白后的 1～120 字符，禁止换行/控制字符；正文最多 100000 字符，允许空正文。

## 保存与导航规则

- 编辑输入立即保留在当前页面内存；只有后端确认后显示“已保存”。
- 同一笔记的请求串行发送；保存期间继续编辑，不会被旧响应覆盖，后续请求使用新 revision。
- 自动保存失败后不无限重试；输入保留，可显式重试或继续编辑后再保存。
- 版本冲突返回409，禁止直接覆盖和导出。复制需要保留的输入，确认后重新加载服务端版本。
- 其他笔记、专题导航、页面关闭/刷新在仍有修改或保存中时提醒。正在发送的请求可能已提交，确认离开不能撤销服务器写入。
- 未保存草稿不写 localStorage；浏览器异常退出、断电或明确放弃输入后可能丢失。需要时先复制备份。
- 网络断开导致保存确认丢失时，服务器可能已写入；重试遇到409属于保护行为，不会静默覆盖。

## Markdown 与引用

- 支持基础格式、表格、列表、代码和删除线；预览使用 React Markdown，不执行原始 HTML。
- 远程图片只显示占位，不自动请求；外部链接只允许 HTTP(S)，点击时在新标签页打开。
- 普通正文中的 `[S1]` 等编号对应保存时的引用快照；代码块、行内代码、链接和图片内的标记不算引用。
- 用户可删除引用标记，快照仍保留，但导出只附正文实际使用的有效引用。
- 不存在的 `[S99]` 可以作为待修改正文保存，但会警告并阻止导出；请修正或放进代码示例。
- 修改结论后保留编号，不代表原文支持新结论。界面和导出文件都会提醒重新核对。

## API

所有接口前缀 `/api/notebooks/{nid}/notes`，后端固定身份，不接受客户端 owner。

| 方法 | 路径 | 行为 |
|---|---|---|
| POST | `/`（实际无尾斜杠） | JSON `origin_message_id`、可选 `title`；新建201、复用200；返回 note/created |
| GET | `/`（实际无尾斜杠） | 笔记摘要列表，不返回长正文和快照 |
| GET | `/{note_id}` | 正文、只读 citations、revision、used_labels、invalid_labels |
| PATCH | `/{note_id}` | title、body_markdown、revision；成功递增 revision |
| GET | `/{note_id}/export?revision=N` | 下载对应保存版本；版本变化409，无效引用422 |

不存在或越过专题/身份范围返回404；不完整回答409；输入/未知字段422；存储故障503。PATCH 不能修改来源回答或引用快照。

## 导出内容与安全边界

下载为 UTF-8 `text/markdown` 附件，包含标题、正文、编辑后复核提示、实际使用的参考资料、位置和原文快照。

- `Content-Disposition` 提供 ASCII 备用文件名与 UTF-8 标题文件名，过滤路径分隔符、控制字符和不安全文件名。
- `X-Note-Revision` 标明版本；客户端核对版本后下载。
- 不额外保存服务端导出副本，不增加内部 API、本机路径或数据库 ID 到导出正文。
- 引用快照使用动态长度的代码围栏，避免原文里的反引号破坏结构。
- 用户自己写进正文的 Markdown 按文本保留，包括 HTML 文本；本应用预览不执行 HTML，第三方 Markdown 渲染器是否执行由其安全设置决定。
- 版本匹配保证下载的是用户请求的保存版本，不承诺导出期间其他页面不能继续修改。
